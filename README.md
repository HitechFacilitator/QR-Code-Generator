## 🎯 About

<p align="center">
  <img src="https://readme-typing-svg.demolab.com?font=Fira+Code&weight=500&size=20&duration=4000&pause=2000&color=4338CA&center=true&vCenter=true&multiline=true&repeat=true&width=800&height=80&lines=Lightweight+web-based+QR+code+generator+built+with+vanilla+HTML,+CSS,+and+JavaScript" alt="About" />
</p>

QR Code Generator is a lightweight, easy-to-use web application that generates QR codes from various input types including emails, passwords, tokens, URLs, and plain text. Designed with security in mind, it helps increase security levels for applications and websites by providing a simple way to generate scannable QR codes. Built with vanilla HTML, CSS, and JavaScript — no frameworks, no dependencies — just pure web technologies. 📱

## 🚀 Getting Started

### Prerequisites

```text
✔ A modern web browser (Chrome, Firefox, Safari, Edge)
```

### Installation

<details>
<summary>📦 Click to expand Installation Steps</summary>

**1. Clone the repository**

```bash
git clone https://github.com/HitechFacilitator/QR-Code-Generator.git
cd QR-Code-Generator
```

**2. No build step required** — This is a zero-dependency vanilla web project.

</details>

### Running the App

<details>
<summary>▶️ Click to expand Running Commands</summary>

Simply open `index.html` in your web browser:

```bash
# On macOS
open index.html

# On Linux
xdg-open index.html

# On Windows
start index.html
```

Or use a local development server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (if installed)
npx serve .
```

Then visit `http://localhost:8000` in your browser.

</details>
